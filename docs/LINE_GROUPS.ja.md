# 家族・夫婦の LINE グループで使う（共有スペース）

家族や夫婦の LINE グループに Genie を招くと、家計簿・買い物リスト・TODO・日程調整を、グループの全員で使えます。グループのほかの人は Genie の利用者でなくてかまいません。

## 始め方

**招待＝すぐ使い始め**です（2026-10-28 改）。「@Genie このグループで使う」と送る必要はありません。

1. Genie の公式アカウントをグループに招きます。Genie は短い挨拶を 1 回だけ送り、そのまま使えます。
2. 「@Genie 〜」「ジーニー、〜」と呼べば答えます。呼ばれなければ割り込みません。
3. グループのほかの人は、Genie の利用者でも、連携していなくてもかまいません。

グループの持ち主（共有の家計簿・リストを持つ人）は、次のように決まります。

- この公式アカウントに連携している人が 1 人だけなら、招かれた時点でその人になります。
- そうでないときは、連携している人がそのグループで最初に話した時点で、その人になります。
- それまでは、「@Genie」に「準備中です」と返します。

## 会話を覚える・呼ばれたときだけ話す

受け取る・覚える・話すを分けています。

- **受け取る**: グループの発言は、LINE からすべて届きます。
- **覚える**: 招かれた直後は**覚えません**（呼ばれた発言だけを使う）。
  - グループの誰かが「@Genie 会話の文脈を使う」と送ると覚え始めます。そのことは返事でグループの全員に知らせます。
  - 覚える期間は既定で 7 日間です。期限が過ぎた発言は DB から消します。送信を取り消した発言は使いません。
- **話す**: 呼ばれたときだけ。
  - 「@Genie 〜」とメンションする。
  - 「ジーニー、〜」で始める。
  - Genie の返事に引用返信する。

「@Genie 設定」で、いまの設定を誰でも確かめられます。設定はボタンで変えられます。

例: 文脈を使う設定で、「土曜ひま？どっか遊びに行かない？」「夕方からならいける」「新宿か渋谷がいいな」のあとに「ジーニー、いい感じの場所探して」と送ると、次のように探します。

- 土曜 17:00・新宿で、遊べる場所を実際に探します。
- 人数は、会話にいる 3 人と仮に置き、そう伝えます。
- 「新宿か渋谷」は希望として扱い、決まったことにはしません。渋谷にしたいときの言い方も添えます。

「@Genie 今の話まとめて」と送ると、次の 3 つに分けて答えます。

- 決まったこと
- まだ決まっていないこと
- 次にやること

会話を覚えていない設定のときは、会話を作り話でまとめません。かわりに次の 2 つの方法を案内します。

- まとめたい内容を貼って送る。
- 「@Genie 会話の文脈を使う」で覚えるようにする。

| 言い方 | すること |
| --- | --- |
| @Genie 設定 | いまの設定を見る（誰でも） |
| @Genie 会話の文脈を使う | 会話を覚え始める（全員に知らせる） |
| @Genie 一時停止 / 黙ってて | 覚えるのも話すのも止める（「@Genie 再開」で、止める前の設定に戻る） |
| @Genie 呼ばれたときだけ | 会話を覚えず、呼ばれた発言だけを使う。覚えていた会話は消す |
| @Genie 覚えるのは24時間 / 7日 / 30日 | 覚える期間を決める（覚え始める） |
| @Genie 今の話忘れて | 覚えていた会話を全部消す |

モデル（Claude）に渡すのは、呼ばれたときの、このグループで覚えている会話だけです。送り主は「メンバーA」などに置き換え、名前や LINE の ID は渡しません。

個人の予定やメールをグループで聞かれたときは、グループでは使わず、本人との 1:1 のトークへ案内します。

Genie を止めるときは、持ち主が「@Genie このグループをやめる」と送ります。それまでに付けた家計簿やリストは残ります。

- 止めたグループは、Genie を外して招き直しても**勝手には再開しません**。
- 再開できるのは持ち主だけで、「@Genie 再開」と送ります。前の家計簿・リスト・設定のまま戻ります。

## みんなの計画（Action Board）

グループで場所を探したり、日程調整をしたりすると、Genie がその話題の**計画のボード**を作ります（2026-10-28）。

- **載ること**
  - みんなの希望: 「新宿か渋谷（希望）」「3 人（仮）」など。
  - 決まったこと
  - まだ決まっていないこと
  - 場所の候補: 写真・評価・地図。
  - 日程の候補: 何人が OK か。
  - これまでの動き
- **開き方**: 候補のカードの「みんなの計画を見る」か、「@Genie ボード」で出るリンクから開きます。リンクは 30 日使えます。
- **LINE の中で開く（LIFF）**: `GENIE_LINE_LIFF_ID` があると、リンクは `https://liff.line.me/<ID>/<リンク>` になり、LINE の中で全画面で開きます。無ければ公開の先頭（`GENIE_PUBLIC_URL`）の直のリンクです。
  - LIFF アプリは、Messaging API のチャネルには作れません。**同じプロバイダーの LINE ログインチャネル**に作ります（友だち追加やグループへの招待は要りません。招待するのは Genie だけ）。
  - 設定: サイズ Full、エンドポイント URL `<GENIE_PUBLIC_URL>/v1/channels/board`、Scope は openid だけ、友だち追加オプション Off。チャネルは「公開済み」にします。
  - LIFF はまずエンドポイント URL に `?liff.state=/<リンク>` を付けて開くので、gateway はそのボードのページへ移すだけです（中継が渡すクエリは `liff.state` だけ）。LIFF の SDK は読み込みません。
  - 一時トンネルの URL が変わったら、LIFF のエンドポイント URL も書き換えます。
  - 同じ LIFF を仕事のホーム（本人 1 人のページ、`services/api-gateway/src/work-home.ts`）にも使います。リンクは `https://liff.line.me/<ID>/w/<リンク>` で、入口が `/v1/channels/work/<リンク>` へ移します。LIFF を 2 つ登録する必要はありません。
- **決め方**: 決めるのは LINE のグループでです（「@Genie 2番目にする」「@Genie 決めて」）。ページはそれを映すだけで、15 秒ごとに読み直します。
- **出さないもの**: 発言の本文・参加者の名前・LINE の ID は、ページに出しません。
- **終わり方**: 「@Genie 計画を終わる」で終えます。

候補のカードの写真は、その店の Google マップの写真だけを使い、撮った人の名前を添えます。写真が取れない店は、写真なしで出します（作った画像では代えません）。

- 誰が足した・買った・済ませたか・行ける日は、LINE の表示名で残します。
- 外国語の文に「@Genie」を付けると、日本語にします。

## 会議を入れる（Google Meet、2026-11-05）

グループで「@Genie 明日15時から30分 打ち合わせ、Meet作って」と頼まれたら:

1. グループの文から日時・長さ・題名を読みます（決まった言い方だけ。モデルには渡しません。
   `services/channels/src/meeting-request.ts`）。読む言葉は Meet・会議・打ち合わせ・ミーティング・MTG のどれかと、時刻です。
   長さが無ければ 1 時間。過ぎた時刻、時刻の無い頼み、問い（「明日の会議は何時？」）は読みません。
2. 持ち主の会話に `calendar.meeting` の仕事を作り、**確認は持ち主の 1:1 トーク**に送ります
   （どのグループの誰から・いつ・何を入れるか）。グループには「持ち主に確認しています」とだけ返します。
   グループに承認のボタンは出しません（グループの誰でも押せてしまうため）。
3. 持ち主が「予定を入れる」を押したら、持ち主の Google カレンダーに `conferenceData`（hangoutsMeet）付きで作ります。
   招待は送りません（`sendUpdates=none`）。Meet の頼みの印はグループの発言 id から作るので、同じ発言の送り直しで会議は増えません。
4. 入れたら Meet のリンクをグループに 1 回だけ送ります。見送ったら「持ち主が見送った」と送ります。

予定を作るには、読む接続とは別の**予定を作る接続**（`google-calendar-actions`、`calendar.events`）が要ります。
まだ無いときは、確認より先に、持ち主の 1:1 に許可の手続きのリンクを送ります（つなぎ直しと同じ道。Mac アプリが
その接続だけの許可の URL を作り、スマホで許可して戻り先の URL を貼る）。1:1 で「カレンダーに予定を入れられるようにして」
と送っても始められます。

## 守っていること

- **グループからは、持ち主の個人のものに触れません。**
  - 個人のものとは、メール、予定、ファイル、個人の家計簿、Genie の仕事のことです。
  - グループの発言は Genie の振り分け（`handleTurn`）には渡しません。読むのは、共有スペースの言い方と共有の家計簿だけです。
  - 「今日のメールを要約して」のような頼みには、「このグループでは分かりませんでした」と答えます。
  - 案内状の写真から予定を読んでも、カレンダーには入れません。「予定に入れるのは 1 対 1 のトークで」と返します。
  - 例外は「会議を入れる」だけです。これも持ち主が 1:1 で「予定を入れる」を押すまで、カレンダーには何もしません。
    グループに返すのは、入れた会議の題名・日時・Meet のリンクだけです（持ち主のほかの予定は出しません）。
- **共有の家計簿と個人の家計簿は分かれています。**
  - グループの家計簿（`expenses.household_id` あり）と、本人の個人の家計簿（なし）は、別々に集計します。
  - 同じレシートを両方に付けても、二重とはみなしません。
- **写真:**
  - 「レシートを自動で読んで」と言うまで、メンションの無い写真は読みません。
  - 読むと決めたあとも、付けるのはレシートだけです。ほかの写真には何も返しません。
  - 写真は Claude で読みます。外へ出るものは [privacy-egress.md](privacy-egress.md) にあります。
- **会話の言い方はモデルに渡しません。**買い物・TODO・日程の言い方は、決まった言い方だけを手元で読みます。
- **共有スペースの置き場所:** 使い始めた人のテナントに置きます（`households`、`channel_groups`）。受信時は `astra_identity` でグループを引くだけで、書くのは持ち主のテナントの中です。

## 制限（未実装・未検証）

- **実際の LINE グループではまだ試していません。**試験は、LINE の API とモデルを代役にした結合テストだけです。
- **グループ会話の要約はありません。**発言を保存しないためです（保存するなら、グループの同意の取り方を先に決めます）。
- **日程調整で、各自のカレンダーは見ません。**行ける日は、各自に答えてもらいます。
- **割り勘、献立、固定費の分析はまだありません。**
- **カードの表示はありません。**Flex Message・カルーセル・Quick Reply・LIFF は使わず、返事はすべて文字です。
- **グループでの予約（リマインダー）は、まだ作れません。**
