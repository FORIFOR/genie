## Read-only source audit

These are source findings and proposed corrections, not measured savings. Source was changing during this review; the previous behavior is recorded so later fixes do not erase the cause.

- **P1, observed load path:** the previous `MeetingTranslation` selection mapped only `ASTRA_LLM_CLI=api` to an external engine; `codex` fell through to local `qwen2.5:7b` when translation was enabled. The previous translation selftest also forced local inference. Thus an externally configured main chat did not guarantee an external translation or a lightweight verification run. The UI agent is implementing direct Codex translation without fallback; the core agent is separating explicit live-model tests from default verification and limiting native build jobs. Their new implementations require their own review and validation.
- **P2, potential backlog:** `Audio/GeminiLiveProvider.swift` schedules every microphone frame onto the main actor and sends WebSocket data without awaiting completion; playback counts queued buffers without a byte cap. `RecordingWorkspace/RecordingRuntime.swift` also dispatches each captured PCM block to the main queue before the bounded mixer. A stalled UI, network, or playback could accumulate work. No heap trace proves this caused the reported crash. A serialized sender and bounded queues with preserved audio storage or an explicit pause would address the risk without changing the model or silently discarding content.
- **P3, small retention:** `Context/ScreenshotContext.swift` caps recent items at twenty but retains `ingestedKeys` until reset. Pruning deduplication keys together with the retained items/TTL would bound growth; this does not explain a multi-gigabyte model residency.

The current native recording path uses Apple Speech, not the legacy Tauri Whisper implementation. Its mixer and persisted recording fragments have bounded buffers. Google live transcription has an explicit pending-byte ceiling. The host processes one claimed step at a time, computer vision has a busy guard, and the dedicated preview had work sync disabled. These bounded paths do not prove the whole app is memory-safe; they narrow this audit's findings.

No heavy build, new inference, native UI test, live stream test, or full-gate rerun was performed by this reviewer. Human parallel input/IME, in-flight native cancellation after the latest fix, and final whole-product release checks remain separate outstanding evidence.
