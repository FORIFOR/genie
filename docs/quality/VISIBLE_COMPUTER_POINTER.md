The direct-runtime smoke excludes the gateway/task-worker path, main app task approval UI, unrelated applications and human concurrent work. It observed click then text input and validates their final combined state; it does not establish strict ordering semantics for arbitrary natural-language tasks. The test supplies fixture-task authorization while retaining the production native target/recipient consent. Its fixture-only startup stages an owned accessory window on the current Space, then makes it regular; production target filtering and all consent checks remain unchanged. Earlier blocked attempts and preflight diagnostics are retained.

The real model initially copied a placeholder frame ID, and later accepted a wrong-coordinate proposal from an unmarked screenshot (`model-target-first-attempt.json`, `model-target-distinct-failed.json`). The final path embeds the actual source ID and requires the native-generated marked context/crop; it never silently falls back to the failed unmarked-image method. Passing the fixed cases is evidence for these cases, not a statistical reliability estimate or proof of error-free model judgment.

Full-gate test fixes preserve live application defaults: render fixtures inject unconfigured settings instead of reading personal Keychain data; state tests inject voice capture instead of opening real microphone/Speech; the macOS shell launcher handles empty Bash 3.2 arrays; native journeys use the current signed app and require an exit receipt. Related focused tests passed. Generated main-app journey artifacts were preserved under `/private/tmp/genie-pointer-main-gate-evidence` and their repository baselines restored; the requested pointer goldens remain in this change.

The stop-control test calls the actual button's `performClick` action and checks revocation and rejection of later input. It does not prove physical pointer hit-testing of that button. Native overlay passivity is verified through panel flags, view hit-testing and foreground/cursor readback, not by clicking through into a personal application.

The implementation is uncommitted and unpushed. The UI repository rule requires the full verification gate to pass before commit. Visible background behavior, native regressions and the direct runtime through production native consent are established; managed-product end-to-end completion and release readiness are not established by these results.

## Remaining verification boundaries

- Real human concurrent typing/IME and usability evaluation are not replaced by automated fixtures.
- Multiple display coordinates are tested deterministically; physical multi-display operation is unmeasured.
- Browser/custom-rendered support remains limited to the existing adapter's operations. Drag, scroll and arbitrary application support are not implemented by this change.
- Managed-preview startup on this machine stopped at Docker Desktop initialization. This is recorded separately from native and direct-runtime results.
