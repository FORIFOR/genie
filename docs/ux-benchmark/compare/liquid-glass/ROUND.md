# One Continuous Surface — 外殻だけ Liquid Glass（2026-09-27、本人の決定）

DS-04（素材は平らな黒）と Craft Freeze の**例外**。本人が「外殻だけ Liquid Glass」を選んだ。中身の面・文字・部品は変えない。

reference : Apple Human Interface Guidelines — Materials / Liquid Glass（macOS 26、2026-09-27）。ガラスは操作の層（浮いた面の外殻）に使い、読む中身はガラスに直接置かない。「透明度を下げる」では不透明に戻す。
hypothesis: 平らな半透明の黒（0.80）は、込み入った地では背後の文字が**くっきり**透け、Dock の文字と重なって読みにくい。外殻を Liquid Glass にしてその上に黒を重ねれば、背後はぼけて色だけになり、文字の地の明るさは今と同じ帯に収まる。
measured  : `--selftest glassshots`（Dock の下に明・暗・込み入った地の窓を敷き、画面のその範囲を撮る。面の中央帯の平均輝度 0–255）。前（平らな黒 0.80）: 明 65〜74 / 暗 5〜17 / 込み入り 36〜50。背後の文字は輪郭のまま透ける（`before/busy-conversation.png`）。
candidates: A = いま（平らな黒 0.80） / B = `glassEffect(.regular.tint(black 0.72))` だけ（測ると明 150〜192・込み入り 142〜154、白い文字が読めない。不採用） / C = `glassEffect(.regular)` の上に黒 0.62 を重ねる（採用）
gate      : 1) 機械: glassshots の輝度（C: 明 60〜79 / 暗 21〜31 / 込み入り 55〜66 ＝ A と同じ帯で、読める側）、`--selftest dock8` 明暗 25 状態（隅の alpha・窓 1 枚・top 固定）、swift test、UI の癖・言葉の gate。2) 盲検 panel: 未実施。3) golden: task-dock（dock8 は窓だけを撮るので背後は写らない。外殻の差は glassshots の before/after で見る）。

## 結果

採用: C。

- macOS 26 以上かつ「透明度を下げる」がオフのときだけガラス。それ以外（macOS 14〜25、透明度を下げる）は A と同じ平らな黒。
- ガラスは `GenieDockShape` で切る。以前 `NSVisualEffectView` / `Material` で出た「角の外の灰色の帯」は、glassshots の明るい地で出ていない（`after/light-agent.png`）。
- 同じ round で直した中身（外殻とは別）:
  - 会話で聞いている間はオーブの面をやめ、入力の大きさで動く波形（直近 14 個）と認識中の文字に戻した（本人の決定「波形＋認識中の文字」）。届く値は振幅の peak で話し声でも 0.05〜0.3 に集まり、棒が 1〜2pt にしかならなかった（実マイクの voicee2e で確認）ので、描くときだけ平方根で広げた。直した後の voicee2e（実マイク）で、話している間の棒が高くなり、言い終えると左へ流れて静まるのを確かめた。
  - 作業中の「50%」をやめ、「2/5 段」（終わった段 ÷ 段の数）にした。途中の段を半分と数えた割合は作った数字だった。
  - 会話で仕事を受け付けたときだけ「かしこまりました。」と言う（受け付けられなければ理由を言う）。
- 撮った絵: `before/` と `after/` に、明・暗・込み入った地 × 会話・作業中。
- 実マイクの通し（voicee2e --mic --burst --shots）: 3 回中 2 回 OK（聞く→送る→読み上げ→次を聞く、23.7s）。1 回はスピーカーから流した声をマイクが文字にできず、聞く段で止まった（声の経路は今回変えていない）。
- 測っていないこと: 「透明度を下げる」を実際に入れた姿（コードは A と同じ経路）。窓の影の見え方の差。盲検 panel。
