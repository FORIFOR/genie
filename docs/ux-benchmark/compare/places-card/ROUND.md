## 決めたこと

採用: B。C は「どこにあるか」を持たず、A は位置関係が読めない（構造の差で、面積・色・影・角丸は既存の値から動かしていない）。

- 地図は Maps Static API の画像（Google の地図）。MapKit は使わない（Places の方針）。同じ面に Google の地図があるので、追加の帰属表示は要らない。
- 地図が取れないときは同じ寸法の枠に「地図を取得できませんでした」。面の高さを変えない。
- 行を押すと、取得元が返した Google マップの https のリンクだけを開く。
- 出す店は 3 件（5 件だと 360 を超える。上限は上げず、件数で収める）。
- 数字は取得元の値だけ。距離は現在地からの直線（端末で計算）であることを、今後ガイドに書く。
- 会話（Gemini）へは「近くのスターバックスを N 件、画面に出しました。」だけ。店名・住所・位置は返さない。
- `dock8` の 06k の地図は **合成**（灰色の地に白い道）。ネットワークと鍵に触れずに撮るため。本物の地図の見え方は本人の鍵での実呼び出しで確かめる。
