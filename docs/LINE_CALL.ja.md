# LINE から Genie と声で話す（通話のページ）

LINE の 1 対 1 のトークで「電話して」と送ると、Genie と声で話せるページのリンクが届きます。リンクを開いて「話しはじめる」を押すと、Genie と話せます。

```
LINE「電話して」→ リンク（10 分・1 回だけ）→ ブラウザのページ → gateway → Gemini Live（声）
                                                                ↘ 頼みは Genie の仕事（LINE の会話と同じ）→ 結果は LINE に届く
```

## なぜ LINE の通話そのものではないか

LINE の通話から Genie につなぐ「LINE コール Plus」は、LINE との契約と、接続事業者の SIP の条件が必要です。そこで、提案にあった代わりの方式（ブラウザで話すページ）を先に作りました。電話番号も Twilio も使いません。LINE の通話につなぐのは、契約の条件が分かってからにします。

## 使い方

1. LINE の Genie とのトークで「電話して」（「通話したい」「Genie に電話」でも可）と送ります。
2. 届いたリンクを開きます。
   - リンクには `openExternalBrowser=1` が付いているので、LINE の中ではなく、いつものブラウザ（iPhone なら Safari）で開きます。
   - LINE の中の画面ではマイクが使えないことがあるためです。
3. 「話しはじめる」を押し、マイクを許可します。話す内容は画面にも文字で出ます。
4. 「切る」を押すか、「切って」「バイバイ」と言うと終わります。

- **話しながら頼めること:** 予定・メール・調べもの・作業などを頼めます。どれも LINE のトークで頼んだのと同じ Genie の仕事になります。
  - Genie がその場で答えられるもの（予約の一覧など）は、Gemini が声で伝えます。
  - 時間のかかる仕事は「確認しますね」と受け、結果は LINE のトークに届きます。
- **チャットとの共有:** 通話とチャットは同じ会話（conversation）です。チャットで頼んだあとに通話で「さっきの件、どうなった？」と聞くと、Genie はそのまま聞かれたこととして扱います。
- **確認が要るもの:** 送信・支払い・確定の前には、これまでどおり承認カードで確かめます。

## 準備（運営者）

キーは Mac の「会話」と同じ Gemini のキーを使います（キーチェーンの `gemini`。二重に持たない。[SECRETS.ja.md](SECRETS.ja.md)）。
鍵ではない設定を `~/Library/Application Support/Genie/channels.env` に書き、プレビューを `--channels-env` 付きで起動し直します（[LINE_SETUP.ja.md](LINE_SETUP.ja.md)）。

```
GENIE_CALL_MONTHLY_MINUTES=60        # 月の上限（分）。0 か未設定なら通話は使えません
GENIE_PUBLIC_URL=https://….trycloudflare.com   # トンネルの URL（リンクの先頭になる）
```

- **中継:** LINE の中継（`scripts/line-webhook-relay.mjs`）は、通話のページ（`GET /v1/channels/call/<リンク>`）と、その音声の WebSocket（`…/ws`）も通します。それ以外の道は、これまでどおり外から届きません。
- **トンネルの URL:** 無料の一時 URL は、起動し直すと変わります。変わったら `GENIE_PUBLIC_URL` も直します。

## 守っていること

- **リンク:** 10 分・1 回だけ使えます。開いた（ページを見た）だけでは使ったことにならず、話し始めた時点で使い切ります。残すのは、24 バイトの乱数のハッシュだけです。
- **月の上限:** 月の上限（東京の暦）と、1 回 10 分の上限を守ります。上限に達したら始めず、途中なら切って理由を出します。
- **残すもの:** 声も文字起こしも残しません。残すのは、通話の時刻・長さ・終わった理由だけです（`call_sessions`）。
- **Gemini へ送るもの:** 送るのは声だけです。Genie の仕事の中身は返さず、返すのは「受け付けた」か、Genie の短い答えだけです。
- **キーの送り方:** キーはヘッダーで送り、URL やログには載せません。
- 外へ出るものの一覧は [privacy-egress.md](privacy-egress.md) にあり、`scripts/verify-privacy-egress.sh` が確かめます。

## 制限（未実装・未検証）

- **本物ではまだ試していません。**試験は、Gemini Live の代役（決まった返事をする WebSocket）を使った結合テストだけです。次のことは確かめていません。
  - 実際の Gemini Live の声の質と遅れ
  - iPhone の Safari での録音と再生
  - LINE の中で開いたときにマイクが使えるか
- **LINE の通話そのもの（LINE コール Plus）にはつないでいません。**
- **音声の送り方:** WebRTC ではなく WebSocket で送っています。電波の悪い所では途切れやすいかもしれません。
- **1 回の通話は 10 分までです。**Gemini の接続の区切りが来たら、続けずに終えます。
- **リッチメニュー（2026-10-29）:** 仕事・電話・予定・使い方の 4 つ。ボタンは本人が打つのと同じ文（「電話して」など）を送るだけで、新しい道は作らない。定義は `services/channels/src/rich-menu.ts`、画像と登録は `scripts/line-rich-menu.mjs`（render・status・apply・remove）。送る文が受ける側に届くことは `services/api-gateway/test/rich-menu.test.ts` で確かめる。

## 通話でできること（2026-10-23 追加）

| 機能 | 使い方 | 中身 |
| --- | --- | --- |
| 割り込み | Genie が話している途中で話す | 再生を止めて、新しい発話を聞く |
| ミュート・終了 | 画面のボタン | 「切る」か「切って」で終わる |
| つなぎ直し | 電波が切れても自動で戻る | 45 秒以内なら同じ通話の続き（Gemini はつないだまま待つ） |
| 声で頼んで声で答える | 「今日のメールを確認して」「今月の食費は？」 | すぐ終わる仕事は 45 秒まで待って声で答える。長いものは LINE に届く |
| 家族の家計簿・リスト | 「家族の家計簿を見せて」「家族の買い物リスト」 | 使い始めたグループの共有スペース（持ち主だけ） |
| グループへ送る | 「さっきの結果を家族のグループに送って」 | 送る前に必ず「送ってよいですか」と確かめる |
| 送った写真の話 | 「さっき LINE に送った写真」 | 直前に読んだ写真の中身（30 分。写真そのものは持たない） |
| カメラ・画面 | 画面のカメラ／画面ボタン | 入れている間だけ 1 秒に 1 枚を Gemini に見せる（料理・冷蔵庫・エラー画面） |
| タイマー・料理 | 「5 分後に教えて」「次は？」 | 予約になる。手順はひとつずつ |
| 通話の議事録 | 電話を切ると届く | 話したこと・決まったこと・次にやること（あなた／Genie）を LINE に残す。Claude が文字起こしから書く。キーが無ければ頼みと答えから組み立てる |
| Genie からの着信 | 「明日 7 時に電話で起こして」 | 時間になると LINE に「電話に出る」。出ると Genie が用件から話す（30 分有効） |
| 家族で話す | グループで「@Genie みんなで話そう」 | 「通話に参加」で 6 人まで。頼みは共有スペースだけ。議事録はグループへ |

## 残っていること

- **WebRTC（LiveKit）への置き換え。**中継を公開の場所に置くときに一緒に行います。いまは WebSocket です。
- **応答の速さ（目標 1 秒以内）は、実際の電話ではまだ測っていません。**
- **家族の通話の話者の識別はできません。**声を 1 本に足して Gemini に送るので、誰が話したかは区別できません。
- **家族の通話で頼めるのは、共有スペースのものだけです。**買い物・TODO・家計簿・日程が対象で、個人のメールや予定は扱いません。
