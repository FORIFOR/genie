# 個人の辞書（音声入力の置き換え）

「こう聞こえたら、こう書く」を登録すると、音声入力で入れる前に置き換えます。同じ語は、聞き取りの手がかりとして音声認識にも渡します。

## 登録・一覧・削除（会話で）

| 言い方 | 意味 |
| --- | --- |
| 辞書に登録: ジーニーは Genie | 「ジーニー」と聞こえたら「Genie」と書く |
| ジーニーはGenieと書くように辞書に登録して | 同じ |
| 「すーぱーいんたーん」は「SuperIntern」と書いて | かぎ括弧があれば「辞書」と言わなくてよい |
| カレンダーリンクと言ったら https://… と入れて | 決まった文を入れる（スニペット） |
| オープンクローを辞書に登録して | 置き換えず、聞き取りの手がかりにだけ使う |
| 辞書を見せて | 一覧 |
| 辞書からジーニーを消して | 削除 |

- 「この文を英語に変えて」「返事は OK と書いて」のような普通の頼みは、辞書の登録とは読みません。辞書の操作と読むのは、「辞書」という語、かぎ括弧、「と言ったら」のどれかがある言い方だけです。
- 同じ聞こえ方をもう一度登録すると、書き方を上書きします。登録できるのは 1 人 300 件までです。
- HTTP でも扱えます: `GET /v1/vocabulary`、`POST /v1/vocabulary`（`{"spoken","written"}`）、`DELETE /v1/vocabulary/:id`。

## Mac での使われ方

- Mac はサインインしたときと、音声入力を始めたとき（1 分に 1 回まで）に辞書を取りに行き、手元に控えます（`dictation-vocabulary.json`、0600）。つながっていない間は、この控えで置き換えます。
- 置き換えは、言い淀みを消した（`DictationCleanup`）あとに行います。**モデルは通しません。**
  - 長い聞こえ方から順に置き換えます。
  - 置き換えた結果を、もう一度置き換えることはしません。
  - サーバの `applyVocabulary` と同じ規則です。
- 置き換えたときは、これまでどおり「元の文に戻す」で、置き換える前の文に戻せます。
- 聞こえ方（30 字まで、100 語まで）は `SFSpeechRecognitionRequest.contextualStrings` として音声認識に渡します。

## 音声入力の履歴（この Mac の中だけ）

- 欄に入れた文（置き換えた後と前）、入れた先のアプリ名、時刻を `dictation-history.json`（0600）に残します。音声は残しません。外へは送りません。
- 7 日を過ぎたものと、100 件を超えた古いものは消します。パスワード欄に入れた文は残しません。
- 設定の「音声入力」で止められます。止めると、それまでの履歴も消します。行はコピーだけです。
- 記録（`~/Library/Logs/Astra/dictation.log`）には、これまでどおり文そのものを書きません。

## 制限（未実装・未検証）

- 設定の「音声入力」でも、一覧・追加・削除ができます（DESIGN.md §8.2）。
- **会議の文字起こし、翻訳、要約には、まだ当てていません。**今は音声入力だけです。
- **実機の音声で、辞書のあり・なしの聞き取りの差は測っていません。**
