# 送るだけで Genie が判断する（写真・外国語の文）

LINE に写真や外国語の文を送るだけで、Genie が中身を読み、何をすればよいかを判断します。機能を選ぶ必要はありません。メニューやボタンも使いません（確かめるときの「はい / いいえ」は文字で答えます）。

## 何をするか

| 送るもの | Genie がすること | 返事の例 |
| --- | --- | --- |
| レシートの写真 | 読んで家計簿に付ける | 食費 ¥2,480を家計簿に付けました。今月の食費は ¥42,180 / ¥60,000です。違っていたら「取り消して」。 |
| 料理の写真 | カロリーと栄養の目安（幅で） | 焼き鮭定食ですね。約 600〜700 kcal（たんぱく質 35g・脂質 20g・炭水化物 75g）。写真からの目安です。 |
| 案内状・招待の写真 | 日時と場所を読んで、予定に入れるか聞く | 予定を見つけました: 保護者会 2026-11-12 10:00〜（体育館）カレンダーに入れますか？ はい / いいえ |
| 外国語の文・写真 | 日本語にする | 英語 → 日本語 悪天候のため、出発が約2時間遅れています。 |
| スクショ・エラー画面・書類 | 何が書いてあるかを短く説明する（外国語なら訳も） | |
| 写真と頼み（「これを〜して」） | 写真の中身を添えて、いつもの頼みとして Genie に渡す | |
| 決められないもの | 短く聞き返す | これをどうしましょうか？ |

**判断の順番**

1. 写真や文の中身を理解します。
2. 添えた文と中身から、目的を推定します。
3. レシート・料理・予定などなら、それに合った処理をします。
4. 外国語が含まれていれば、必要なことを日本語で返します。英語のレシートなら、訳ではなく家計簿に付けます。
5. 決められないときだけ、短く聞き返します。

翻訳は独立した機能ではなく、どの処理にも入っている共通の能力です。

## 確かめるのは 2 つのときだけ

- **レシートの読みに自信が無いとき。**次のどれかに当たれば「家計簿に付けますか？」と聞きます。
  - 確かさが 0.85 未満
  - 明細の合計と支払いの合計が合わない
  - 日付が読めない、または 1 年より前・未来になっている
  - 円ではない
- **予定に入れるとき。**「はい」と答えると、カレンダーへの頼みとして Genie の仕事になります。カレンダーへの書き込みは、そのあと承認カードでもう一度確かめます。

ほかは確かめずに済ませ、結果だけを 1〜3 行で返します。

## 家計簿

- **付けたもの:** 送った直後（30 分以内）なら「取り消して」で取り消せます。取り消した行は消さず、印を付けて残します。
- **二度付けない:** 同じレシートは付けません。店・日付・合計が同じものか、同じ写真なら「もう付けてあります」と答えます。
- **会話でできること:** LINE でも Task Dock でも使えます。
  - 「家計簿を見せて」: 今月の費目ごとの合計
  - 「今月の食費はいくら？」: その費目の合計と予算の残り
  - 「食費の予算を 6 万円にして」: 月の予算を決める
- **費目:** 食費・外食・日用品・交通・医療・衣服・娯楽・光熱費・通信・その他
- **写真は残しません。**残すのは、読んだ値（金額・費目・店・日付）と、同じ写真を見分けるための指紋（SHA-256）だけです。

## 外国語の文

- かなを 1 字も含まない文だけを、外国語らしいとみなして読みます。日本語の文は、これまでどおり Genie にそのまま渡し、モデルにも送りません。
- 訳したあとに「これに返信して」と送ると、相手の言語で返信の案を作ります。「これに返信して、来週なら大丈夫と」のように、返したいことを添えることもできます。
- 外国語で頼みを書いた場合（例: "Please summarize my schedule for tomorrow"）は、日本語の頼みに直してから Genie に渡します。

## 準備（運営者）

- gateway に `GENIE_UNDERSTAND_ANTHROPIC_API_KEY` を置きます（無ければ `ANTHROPIC_API_KEY` を使いますが、そのときは調べもの・議事録も Claude を使い始めます）。手元のプレビューでは、キーチェーンの `anthropic`（`pnpm secrets set anthropic`）から渡します（[SECRETS.ja.md](SECRETS.ja.md)）。モデルは既定で `claude-opus-5-5` で、`GENIE_UNDERSTAND_MODEL` で変えられます。
  - 安全の判定で断られたときは、同じ頼みを別のモデルで読み直します（server-side fallback）。
- キーが無いときは、写真には「この Genie では、まだ写真を読めません」と答えます。外国語の文は、いつもどおり Genie に渡します。
- 外へ出るものと条件は [privacy-egress.md](privacy-egress.md) に書きました。`scripts/verify-privacy-egress.sh` が次のことを確かめます。
  - Anthropic の SDK を使っているのが `services/understand/src/model.ts` だけであること
  - キーがあるときだけ読む部品を作ること
  - 日本語の文を送らないこと

## 制限（未実装・未検証）

- **実際の LINE 公式アカウントと Claude では、まだ確かめていません。**どちらも代役を使ったテストだけです。
  - LINE の写真の取得: 写真の中身を差し替えた代役
  - モデル: 決めた答えを返す代役
  - 実物のレシートの読み取りの正確さは、まだ測っていません。
- **グループ（家族・夫婦の共有家計簿・買い物リスト・TODO・日程調整）は [LINE_GROUPS.ja.md](LINE_GROUPS.ja.md)。**1 対 1 のトークでも「牛乳を追加」「TODO」で、本人の個人のリストを使えます。
- **写真のほかは読めません。**音声・動画・PDF・URL には「まだ読めません」と答えます。Slack の添付ファイルも読みません。
- **確かめ中の案と「直前に付けたもの・訳したもの」は gateway の中にだけ持ちます。**それぞれ 10 分・30 分で消え、gateway を起動し直したときも消えます。消えたら、もう一度送ってください。
- **Mac の画面からはまだ見られません。**家計簿のグラフや編集の画面（LIFF を含む）もありません。
