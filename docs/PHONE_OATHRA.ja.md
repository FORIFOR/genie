# Oathra 経由の電話

Genie は、Oathra（電話をかける AI の基盤）に委任された範囲で電話を使います。できることは次の 3 つです。

| できること             | 入口                                                     | 承認                                     |
| ---------------------- | -------------------------------------------------------- | ---------------------------------------- |
| 営業の電話             | 「田中さんにデモ商品の資料送付について営業電話をかけて」 | Genie の承認カード（1 件ごと）           |
| 伝言・確認の電話       | 「090-1234-5678 に電話して、明日の集合は10時だと伝えて」 | Genie の承認カード（1 件ごと）           |
| 受けた電話を仕事にする | Oathra の番号にかかってきた電話                          | 外へ出る操作は、これまでどおり承認カード |

**上限は Oathra 側が決めます。**相手（電話番号）、回数、1 通話の金額と時間、期限は、Oathra の委任に書かれた範囲を超えられません。Genie から委任を広げる方法はありません。

## 準備

1. Oathra で、会話データの取り扱いに同意します。営業電話をかける相手を連絡先に登録し、関係（問い合わせ・顧客・同意済み）と、連絡する根拠を書きます。商品の情報も登録して確認しておきます。
2. Oathra の運営者のトークンで、Genie 用の接続を発行します。

   ```sh
   node apps/gateway/connect-agent.mjs --url https://<oathra> --token-file <運営者トークンのファイル> \
     --phone <相手の番号> --allow-sales --read-inbound --approve --output /secure/oathra-connection.json
   ```

   `--allow-sales` を付けたときだけ営業電話を、`--read-inbound` を付けたときだけ着信の読み取りを許可します。どちらも、付けなければ無効です。

3. Genie の gateway と task-worker に、次の環境変数を設定します。
   - `GENIE_OATHRA_CONNECTION_FILE`: 上で作った接続ファイル（0600）
   - `GENIE_OATHRA_OWNER`: `<tenantId>:<userId>`（電話を任せる Genie の利用者）
   - 着信を仕事にする場合は `GENIE_OATHRA_INBOUND=on`

## 営業電話の決め方

- 「営業」「案内」「商談」「アポ」などの言葉と、「電話して・かけて」がそろったときだけ、電話の依頼として扱います。「営業電話のコツ」「電話番号を調べて」は電話になりません。判定にモデルは使いません。
- 相手は、Oathra の連絡先のうち名前（または会社名）が文中に出てくる一人に決まったときだけ選びます。二人以上いる、だれもいない、関係や根拠が未登録、再連絡停止になっている、のいずれかなら電話の仕事は作らず、直し方を返します。
- 目的は、日程・商談なら「商談の日程を決める」、資料なら「資料を送ってよいか確かめる」、それ以外は「サービスを紹介する」です。
- 承認カードには、相手・商品・目的・用件が出ます。発信の直前にも Oathra の連絡先を読み直します。カードに出た相手と違っていたり、許可が外れていたりすれば、電話はかけません。

## 結果の扱い

- 同じ仕事は、Oathra 上でも 1 件の電話です（operation key `genie-<taskId>-<step>`）。応答が失われても、かけ直しにはなりません。
- 「会話で確認済み」は、会話の中で了承を確かめたという意味です。成約や、予定・契約がほかのシステムに登録されたことまでは意味しません。
- 相手が断った場合は、その結果を残し、かけ直しません。結果がはっきりしない（要確認）・失敗・不明の場合は、Oathra の記録を確かめてください。不明のときは、かけ直さないでください。
- 会話の記録は成果物に引用します。相手の発言は記録として扱い、Genie への指示にはしません。

## 着信

- 所有者の SMS 確認済み番号からの電話は、本人の頼みとして、チャットと同じ振り分けで仕事にします。発信者番号は偽装できるため、電話や送信など外へ出る操作には、これまでどおり承認カードが要ります。
- それ以外の人からの電話は、用件の整理と折り返しの案を作るだけです。相手の言葉を指示として実行しません。
- 予約受付の電話は、Oathra の台帳だけで完結するので、Genie の仕事にはしません。
- 同じ着信から仕事を 2 度作ることはありません（`oathra-inbound:<callId>`）。

## 制限（未実装・未検証）

- 接続はサーバーごとに 1 人分です（`GENIE_OATHRA_OWNER`）。利用者ごとの接続管理は、まだありません。
- 実回線（PSTN）での通話は未検証です。確認したのは Oathra の模擬モード（`simulator`）との結合までです。実電話を試すときは Oathra の手順（`--level local` → `gateway` → `pstn`）に従い、PSTN は本人の明示的な了承を得てから行ってください。
- Genie の仕事を止めても、すでに始まった Oathra の通話は自動では止まりません。止めるには Oathra 側で操作してください。
- LINE / Slack からの依頼は Phase 0（署名の確認と、受信した内容の正規化）までです。Webhook の受け口とアカウント連携は、次の段階で作ります。
