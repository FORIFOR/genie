# opencode のセッションを見守る

LINE（または Mac の Genie）で、opencode のセッションの URL を添えて頼みます。

> このセッションを10分ごとに見て、止まっていたら続けさせて http://100.98.145.90:4096/server/…/session/ses_…

Genie は決まった間隔で opencode の API を見て、止まっていて終わっていなければ「続けてください」と送ります。**画面は見ません**（画面操作の承認も、画面を読むモデルも要りません）。

| 見えたもの                                                       | すること                                              |
| ---------------------------------------------------------------- | ----------------------------------------------------- |
| 作業中（busy・retry）                                            | 何もしない                                            |
| 承認・質問を待っている                                           | 促さない。1 回だけ知らせて、見続ける                  |
| 最後の返答に「【完了】」の行がある／促したあとで TODO が全部済み | 終わり。知らせて止める                                |
| 止まっていて、前に促してから新しい返答がある                     | 「続けてください」を送る（最初と 6 回ごとに知らせる） |
| 促しても 3 回続けて新しい返答が無い                              | 止めて知らせる                                        |
| 3 回続けてつながらない・12 時間たった                            | 止めて知らせる                                        |

- **間隔:** 「15分ごと」「1時間おき」のように書けば、その間隔（5 分〜2 時間）。無ければ 10 分。
- **やめる:** 「見守りをやめて」。同じセッションをもう一度頼むと、新しい間隔で始め直す。
- **もう一度:** 「もう一度 opencode を見守って」（URL なし）で、前に見守ったセッションを始め直す。
- **様子を聞く:** 「opencode の実装は終わった？」で、見守りの状態・いまのセッション（作業中／待ち／止まっている）・TODO の残り・最後の返答を答える。
- **知らせる先:** 頼んだチャットの会話。Mac の Task Dock から頼んだときは、本人の LINE。
- **送る文:** 「続けてください。…すべて終わって確かめられたら、最後に【完了】とだけ書いた行を入れてください。（Genie の見守りから・n 回目）」

## 守っていること

- **見に行く先は、手元・社内・Tailscale のアドレスだけ**（127.x、10.x、172.16〜31.x、192.168.x、100.64〜127.x、`.local`、`.ts.net`）。URL に書かれた外のサーバへは送らない。Web の画面の URL がサーバを base64 で持っていても、その先が外なら断る。
- 残すのは、どこを見るか・最後の返答の印（id と時刻）・回数だけ（`opencode_watches`）。セッションの本文は残さない。知らせに添える最後の返答は 200 字まで。
- opencode の API に認証は付けない（手元のサーバの前提）。

## 実装

- `services/api-gateway/src/opencode-watch.ts`（URL の読み方・判断・見回り。gateway が 30 秒ごとに、時間が来たものだけ見る）
- `infra/db/migrations/20261025090000_opencode_watches.sql`
- 試験: `test/opencode-watch.test.ts`（判断）、`test/opencode-watch.integration.test.ts`（本物の DB と opencode の代役）
